# Bommels gemeinsame Suchkarte

Direktlink: https://helfernetz.com/bommel/

Die Seite ist absichtlich nicht in Navigation oder Sitemap enthalten. `noindex,nofollow` steht im HTML; robots.txt lässt das Abrufen zu, damit Suchmaschinen die Anweisung lesen können. Der Link ist für Helfer ohne Anmeldung nutzbar.

Die Karte unterstützt gemeinsame Flächen, Suchwege, Sichtungen und Hinweise. Speicherung und API liegen auf dem zugehörigen Sites-Projekt `appgprj_6aec64208324819199f6cccef25aee5c`; hier wird die öffentliche Einstiegsseite mit den vorhandenen Helfernetz- und VACH Systems-Logos bereitgestellt. Die UI-Ressourcen werden von diesem Projekt geladen.

Bearbeitung eigener Einträge erfolgt über einen zufälligen Schlüssel im Browser. Nach Löschen des Browserspeichers oder auf einem anderen Gerät können diese Einträge nicht als eigene bearbeitet werden. Einträge sind für alle Besucher des Links sichtbar.

Die Grundkarte zeigt Suchvorschläge, keine tatsächlichen Sichtungen. Wege Richtung Zuhause sind mögliche Fußverbindungen. Gemeinsam eingetragene Sichtungen bleiben unbestätigte Meldungen.
